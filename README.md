[![CI](https://github.com/Lithnio/csi500-alpha-research/actions/workflows/ci.yml/badge.svg)](https://github.com/Lithnio/csi500-alpha-research/actions/workflows/ci.yml)

本项目基于 Tushare Pro 构建中证 500 横截面研究样本，覆盖历史成分、因子检验、预期收益、风险估计、主动组合优化、次日开盘执行和结果审计。研究数据按当时可得信息对齐，回测计入停复牌、涨跌停、ST 限制、成交容量、印花税和冲击成本。

> **v2.0.0 结论：** 2020—2025 年六个滚动年度研究折中，组合累计收益为 81.34%，同期中证 500 为 65.22%；累计相对收益为 9.76%，年化主动收益为 1.64%，信息比率为 0.388，5/6 个年度取得正主动收益。结果没有通过预先登记的全部绩效与风险门槛，因此本版本发布为可复现的量化研究实现，不宣称策略已达到实盘标准。

## 研究设计

| 区间 | 用途 |
|---|---|
| 2016 | 长窗口因子、复权与风险估计预热 |
| 2017—各评价折开始前 | 扩展训练窗与折内因子筛选 |
| 2020—2025 | 六个互不重叠的年度评价折 |

```text
供应商数据 → 时点一致股票池与因子 → 折内稳定性与成本筛选
          → 因子家族合成 → 滚动收益校准 → 风险估计
          → 主动组合优化 → 次日开盘执行 → 净收益与完整性审计
```

标签定义为决策日后第一个开盘价至第六个开盘价的个股收益减中证 500 收益。训练样本必须在拟合日前完成标签观测，并设置 5 个交易日隔离期。因子在每日截面内进行稳健缩尾、市值和行业中性化及标准化。

## 因子池与审计

候选池包含 42 个反转、动量、风险、流动性、规模、估值、质量、成长、投资、应计和交互因子。正式审计覆盖 2017—2025 年 438 个决策日和 21.9 万条截面记录，联合检查覆盖率、可得时点、有向秩相关 IC、年度稳定性和扣费五分组价差，共有 14 个因子通过门槛。

| 家族 | 通过审计的因子 |
|---|---|
| 估值 | `book_to_market`、`cfo_yield_ttm`、`earnings_yield_ttm`、`sales_to_price_ttm` |
| 风险 | `low_downside_vol_60`、`low_idio_vol_60`、`low_range_vol_20` |
| 流动性 | `amihud_20`、`free_turnover_20` |
| 质量 | `cash_return_on_assets_ttm`、`gross_profitability_ttm` |
| 成长 | `roe_change_yoy` |
| 动量 | `momentum_250_20` |
| 应计 | `total_accruals_ttm` |

![因子池审计与年度衰减](docs/assets/v2-factor-audit.png)

42 个因子的平均覆盖率为 95.1%，未发现未来数据、陈旧值或未来报告期违规；14 个入选因子在绝对相关系数 0.75 的阈值下形成 12 个连通分量。2025 年仅 7/14 个因子的扣费多空价差为正，中位数降至每次调仓 0.71 个基点，近期信号衰减较明显。全样本审计只用于诊断，年度回测仍在各折训练窗内重新筛选。

全部因子定义、方向和数据可得时点见 [TECHNICAL.md](TECHNICAL.md)。

## 因子合成与组合构建

每次拟合先按覆盖率、IC 方向、分段一致性、扣费价差、信号变化率和相关性筛选 5—10 个因子。入选因子先在经济家族内按预设方向等权，再在有效家族之间分配权重：

$$
F_{g,t}=\frac{1}{|S_g|}\sum_{i\in S_g} d_i z_{i,t},
\qquad
s_t=\sum_g w_gF_{g,t},
\qquad
w_g\le 35\%,\quad w_i\le 20\%.
$$

其中，$d_i\in\{-1,1\}$ 为预先登记的因子方向。滚动岭回归把综合分数 $s_t$ 校准为未来五个交易日的预期主动收益 $\hat r_t$。组合相对中证 500 基准求解：

$$
\max_w\quad
\hat r^{\mathsf T}(w-b)
-\gamma (w-b)^{\mathsf T}\Sigma_H(w-b)
-C(w-w^-)
-\lambda\lVert w-b\rVert_2^2.
$$

约束包括多头满仓、单票权重 3%、单票主动权重 ±1%、行业主动暴露 ±2%、主动 β ±0.05、年化跟踪误差 5%、常规换手 35% 和单日成交量 5%。执行发生在下一交易日开盘，先卖后买，并重新检查涨跌停、停牌和成交容量。

## 方法选择与稳定性检验

在相同训练、风险、优化和执行口径下，研究比较了冻结的 42 因子方案与加入 6 个 A 股交易行为候选后的扩展方案。

| 指标 | 冻结方案 | 扩展方案 |
|---|---:|---:|
| 累计相对收益 | 9.76% | 10.99% |
| 年化主动收益 | 1.64% | 1.84% |
| 信息比率 | 0.388 | 0.428 |
| 主动最大回撤 | -6.64% | -6.95% |
| 正主动收益年度 | 5/6 | 4/6 |
| 最差年度主动收益 | -0.34% | -0.98% |
| 平均单期换手 | 2.22% | 2.88% |
| 累计模型交易成本 | 3.61% | 4.86% |

![备选因子扩展的年度稳定性检验](docs/assets/v2-freeze-rationale.png)

扩展方案的全期年化主动收益高出 0.20 个百分点，但六个年度增量的中位数为 -0.15 个百分点，正主动收益年度由 5 个降至 4 个，同时换手、成本和最差年度均变差，因此没有替换冻结方案。

另一项检验把新增信号先对核心信号做截面残差化，再以时序折外的扣费增量证据决定是否进入组合，并设置换手预算。2020—2025 年所有折中，候选信号的实际组合占比均为 0，最终持仓与冻结方案逐日一致。该结果验证了弱证据下的保护性回退，但不构成新增主动收益。

## 实现内容

| 模块 | 实现 |
|---|---|
| 数据 | Tushare 请求缓存、年度分区、动态指数成分、复权、历史行业、名称与停复牌区间、质量检查 |
| 因子 | 42 因子目录、财务可得时点、缺失规则、截面处理、IC、五分组和跨年稳定性审计 |

| 风险与组合 | Ledoit–Wolf 协方差、60 日 β、主动权重、行业、换手、单票、跟踪误差和容量约束 |
| 执行 | 次日开盘、先卖后买、不可交易方向、部分成交、印花税、线性成本与冲击成本 |
| 复现 | 配置驱动实验、年度折并行、失败恢复、输入与源码指纹、聚合报告和离线测试 |

## 复现

要求 Python 3.12。Tushare 访问令牌仅写入被 Git 忽略的 `.env`。

```powershell
uv sync --extra dev --extra report
Copy-Item .env.example .env

uv run python -m csi500_alpha doctor --config configs/full.yaml
.\scripts\download_tushare.ps1
.\scripts\download_eligibility.ps1
.\scripts\download_financial.ps1

.\scripts\run_factor_audit.ps1
.\scripts\run_v2_release.ps1 -Mode Run -Workers 4

uv run python -m pytest
uv run ruff check .
uv run mypy src
```

市场数据和逐行研究制品不随仓库分发，因此克隆仓库后不能直接还原图中的净值路径。使用者可凭自己的 Tushare 权限按相同配置构建数据并复算。年度任务、报告生成和证据核验的完整命令见 [TECHNICAL.md](TECHNICAL.md)。
